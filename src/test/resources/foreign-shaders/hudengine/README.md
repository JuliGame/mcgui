The text vertex shaders [HUDEngine](https://github.com/Nacvark/HUDEngine) 1.1.0 generates (MIT licence),
written out from its `ShaderGen` with one HUD state, as a pack the way it ships one: a HUD plugin that replaces
Minecraft's text vertex shader. `ForeignShadersTest` merges MC GUI's text shaders into it.
